# Deep Learning Hands-On Repository 🚀

A comprehensive hands-on collection of deep learning and machine learning implementations, ranging from tabular data classifiers to advanced Natural Language Processing (NLP) sequence prediction and intent classification tasks.

---

## 📂 Repository Structure & Notebooks

### 1. Tabular Data Classification
* **Deep Learning with FFNN**: Hands-on implementation of a multi-layer Feed-Forward Neural Network (FFNN) using PyTorch for tabular data classification, covering the complete pipeline from data loaders to training loops and evaluation metrics.

### 2. Conversational Intent Identification (Banking77 Project)
An end-to-end NLP pipeline analyzing the `banking77` dataset for fine-grained intent classification across 77 distinct banking scenarios.

* **01. Data Understanding + EDA**: Exploratory Data Analysis of intent distributions, text lengths, and dataset characteristics.
* **02. Text Cleaning**: Text preprocessing, normalization, and tokenization pipelines.
* **03. NLP Baseline**: Traditional machine learning baselines combining TF-IDF feature extraction with Logistic Regression (LR) and XGBoost.
* **04. LLM Embeddings & Classifiers**: Comparison between dense neural embeddings and sparse feature vectors for classification performance.
* **05. Parameter-Efficient Fine-Tuning (PEFT - LoRA)**: Modern transformer adaptation using Hugging Face, applying Low-Rank Adaptation (LoRA) on pre-trained BERT/DistilBERT models for efficient intent recognition.

---

## 🛠️ Tech Stack & Frameworks
* **Deep Learning**: PyTorch, Hugging Face Transformers & PEFT
* **Traditional ML**: Scikit-Learn, XGBoost
* **Data Processing**: Pandas, NumPy
* **Environment**: Jupyter Notebooks
